# 🌤️ Weather React App

A simple and responsive **Weather Application** built using **React** that fetches real-time weather data from the **OpenWeatherMap API**.

---

## 📌 About the Project

This project allows users to search for a city and view its current weather details such as temperature, humidity, wind speed, and weather conditions.  
It demonstrates API integration, React hooks, and clean UI handling.

---

## ✨ Features

- Search weather by city name  
- Real-time weather data using OpenWeatherMap API  
- Displays temperature, humidity, wind speed, and weather condition  
- Responsive user interface  
- Basic error handling for invalid city names

---

## 🧰 Tech Stack

- **React**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**
- **OpenWeatherMap API**

## 🛠️ Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/Harshkc10/weather-react.git
   cd weather-react

2. **Install dependencies**
   ```bash
   npm install
   
3. **API Key Setup**
   ```bash
   Create an account on https://openweathermap.org/
   
   Generate your API key
   
   Create a .env file in the project root
   
   Add the following inside .env:
   
   env
   Copy code
   REACT_APP_WEATHER_API_KEY=your_api_key_here

4. **Run the project**
   ```bash
   npm start
   The application will run locally at:
   http://localhost:3000
